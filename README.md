# 💬 My Avatar – Your AI-Powered Digital Twin
**My Avatar** is an AI-powered digital twin of myself — a personal agent that can intelligently answer questions about my **career**, **aspirations**, **experiences**, **qualifications**, and even aspects of my **personal life**. Inspired by the concept in *Black Mirror*, this agent is a digital manifestation of my alter ego. Just ask it anything you'd ask me — it’s designed to respond naturally and contextually, as if you were speaking to me directly.

## 🧠 What It Can Do
- 🗣️ Answer questions about my background, journey, and expertise
- 🔔 Send push notifications when it detects specific prompts like:
  - "I'd like to get in touch"
  - Questions it can’t answer confidently
- 🤖 Behaves like a conversational interface to my digital persona

> Think of it as your personal window into my professional and personal world.
---

## 🚀 How to Run the App
### 🔧 Backend (Server)
1. Navigate to the server directory
2. npm run dev

### 🌐 Frontend (Client)
1. Navigate to the client directory
2. npm run start

📦 Tech Stack
Frontend: React + TypeScript
Backend: Node.js + Express
AI: Integrated with a large language model (LLM) via API
Notifications: Triggered based on natural language patterns

🧪 Example Prompts You Can Try
“What projects has Kaiwei worked on?”
“Tell me about your experience.”
“What are your future aspirations?”
“I’d like to get in touch.” ➜ (Triggers a notification)

🖤 Inspiration
This project was inspired by the Be Right Back episode of Black Mirror, where technology creates an AI version of someone based on their digital footprint. This is a more intentional, controlled version of that idea — built to share, not replace.
